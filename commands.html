Commands

Everything you need to play and configure.

Poro Hunt uses slash commands. Most gameplay happens through menus/buttons so channels stay clean.

Player commands

These are the main commands for server members.

Open the game menu

Recommended
/menu

Your main hub for Poro Hunt (quick access without cluttering channels).

View the showcase

Player
/showcase

Shows the server’s showcase output (what it displays depends on your setup).

View the leaderboard

Player
/leaderboard

See top players and standings for your server.

Tip: Most interactions happen through menus/buttons to keep chat readable. If your bot uses private responses, players won’t spam the channel when they play.

Admin commands

All admin tools are run as /poro admin <command>.

Set spawns per day

Admin
/poro admin spawnsperday

Adjust how many spawns the server can get per day.

Set the spawn channel

Admin
/poro admin channel

Choose which channel poros will spawn in.

Set the showcase channel

Admin
/poro admin showcase-channel

Choose which channel receives showcase posts/updates.

Clear the current spawn

Admin
/poro admin clearspawn

Removes the active spawn (helpful if something gets stuck).

Reset everything

Admin
/poro admin resetall

Resets server data/settings. Use with caution.

Run setup

Admin
/poro admin setup

Runs initial setup and prepares the server for spawns.

Force a spawn

Admin
/poro admin spawn

Manually triggers a spawn (useful for testing or events).

Best practice: Put spawns in a dedicated channel so the rest of your server stays clean.
