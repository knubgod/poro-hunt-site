About Poro Hunt

Poro Hunt is a Discord mini-game where poros appear in a channel and players try to catch them. The focus is simple: keep things fun, keep things lightweight, and keep chat readable.

Spawns are public to create shared moments, while outcomes can remain private so servers can continue their normal conversations without clutter.

About the developer

Poro Hunt is built by KnubGod — a Discord server admin and developer who wanted a bot that feels like it belongs in real communities.

The goal is a satisfying collection loop, clean interaction design, and real admin controls — without spam and without pay-to-win mechanics.

Project values

Built to be fun in public, tidy in practice, and easy for admins to manage.

Low noise

Private results and minimal clutter so your server stays readable.

Server control

Configurable channels and timers so it fits your community vibe.

Fair play

No pay-to-win. Donations support hosting and development only.
