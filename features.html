Features

Everything you can tune for your server.

This page is intentionally more detailed — the homepage is for the pitch, this is for the “okay, but how does it work?”

Spawn system

Poros appear in configured channel(s). Your community gets the moment without constant noise.

Despawn timer

Spawns can expire automatically. No clutter, no “stuck” messages hanging around.

Boosts

Berries boost odds for a spawn. Keeps players making decisions instead of mindlessly clicking.

Collections

Successful catches add to personal progress and give people a reason to return.

Private outcomes

Catch results/rewards can be delivered privately, keeping your channel readable.

Server settings

Adjust spawn timing, which channels are used, and balance knobs as the bot evolves.

Why servers keep it

The bot is designed around “fun per message.” If it doesn’t add value, it shouldn’t post.

It respects the chat

Public spawns are the only necessary channel messages. Everything else can be private.

It creates moments

A spawn is a mini-event. The point is the shared “everyone rushes to catch it” energy.
